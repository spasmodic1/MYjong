MYjong 0.9.12 adds recorded instruments and recurring seasonal red rabbits.

- All eleven music tracks now use recorded grand piano, concert harp, glockenspiel, bowed glass and sleigh bells, with richer stereo room ambience. Everything remains bundled for offline playback.
- Seasonal puzzles include a separate Red rabbit pair alongside the existing holiday pictures. Eleven themes use the reviewed seasonal rabbit artwork; the others retain the classic red rabbit.
- Winter, Easter, Spring, Summer, July and School rabbits use natural red fur and simple seasonal accessories. Gold is retained for Valentine and St. Patrick variants.
- Includes the compact Seasonal settings dropdown, clearer Next puzzle mode label and theme selector, score button improvements, and delayed-playback fix from 0.9.11.

Use Settings → Check for Updates, or install MYjong-Setup-0.9.12.exe.

MYjong 0.9.11 keeps Settings compact.

- Show the next puzzle’s theme on the toolbar and in New Game; keep the current theme until the puzzle ends. Guard against delayed music playback restarting an old track.
- All seasonal preferences are now inside a single Seasonal settings dropdown, closed by default.
- The expanded list scrolls within a bounded panel. Theme selections and saved preferences are unchanged.
- The score-saving button now reads Save High score, uses the gold primary style, and gently glows until saved. Reduced-motion settings disable its pulse.

Use Settings → Check for Updates, or install MYjong-Setup-0.9.11.exe.

MYjong 0.9.10 simplifies seasonal matching.

- Removed seasonal number markers and numbered names. Candy matches Candy, and all seasonal names follow Show names.
- Each picture now has one matching identity. Existing numbered puzzles migrate with their board, undo/shuffle history and race arrivals preserved.
- Seasonal mode and theme choices apply to the next puzzle. Current puzzles keep their theme across preference changes, month boundaries and reloads.

Use Settings → Check for Updates, or install MYjong-Setup-0.9.10.exe.

MYjong 0.9.9 brings painted tiles and a year of seasonal scenery.

- All 35 traditional tile faces now use original painted artwork, including the red-and-gold rabbit. All 126 seasonal illustrations match the botanical scenic style.
- Eighteen automatic monthly themes add static scenic backgrounds, coordinated tile finishes and optional seasonal faces. Choose individual celebrations and monthly favorites in Settings. Christmas is the December default; Hanukkah and Winter Solstice are optional.
- A small top-bar preview switches seasonal mode on or off without replacing the current puzzle. Seasonal faces mix with traditional tiles by default; All seasonal is also available. Match the same seasonal picture and number. Number markers remain visible when names are hidden.
- Five original seasonal music arrangements cover winter, spring/Easter, Halloween, Christmas and Hanukkah. Seasonal music is optional and respects the music and volume controls. Local audio now supports seeking and reliable duration metadata.
- The game checks for updates quietly on launch, with a small notice when a newer release is available. Downloads and installation still require confirmation.
- Fixed tile sizing across artwork types. All scenery, illustrations and music are bundled for offline play. Existing photos, names, scores and saved puzzles are preserved.

Use Settings → Check for Updates, or install MYjong-Setup-0.9.9.exe.

MYjong 0.9.8 adds an uninstall prompt to remove all MYjong data for the current Windows user. Choose Yes to permanently remove stored photo copies, saves, scores, settings and caches, No to keep them, or Cancel to stop. Updates preserve data. Original photos and externally saved backups are untouched.

MYjong 0.9.7 sets first-run defaults to Random layout, Relaxed difficulty, Photos & traditional tiles, Match the same person or pet, and Relaxed play. Appearance and audio defaults use Evening blue, porcelain Classic tiles, Comfortable text, names and blocked shading off, sounds on, music off, Garden walk/Moonlight tunes, and 45% volume. Race arrivals default to 5 seconds after the opening grace period; Memory reveals default to 4 seconds. The starter collection seeds photos without overriding these defaults.

MYjong 0.9.6 restores mixed incoming tiles without changing existing faces. Each drop matches an available face when possible; later drops supply missing partners. Race mode keeps counting down when no matches are open.

MYjong 0.9.5 repairs an unresponsive startup caused by a damaged packaged archive.

- Rebuilt the application from stable source files. Packaging now verifies every runtime file against its source before the build succeeds.
- Includes maximized launch and the welcome screen, custom menu colors and live tile previews, the Memory reveal timer, revised race drops and explicit full-board losses, and the red rabbit tile.
- Existing photos, names, settings, scores, and saved puzzles are preserved.

Install `MYjong-Setup-0.9.5.exe` to repair the affected 0.9.4 build.

MYjong 0.9.4 adds richer music, distinct layouts, and Memory mode.

- Six longer original arrangements layer piano-like and harp-like instruments, soft chords, bass, stereo room reflections and melodic variations. Menu and game tunes can be chosen separately and crossfade when menus open or close.
- Diamond now has pointed tips, Terrace has a stepped pyramid, and Butterfly has separated wings and a narrow body. Starting deals remain solvable at all difficulties.
- Memory mode starts with hidden faces. Clicking an available tile flips it over; choosing another hides the previous face. Matching pairs disappear. Flip animations respect reduced-motion settings.
- New puzzles receive a quick falling-tile deal animation. Reduced-motion users get an immediate board.

Use **Settings → Check for Updates**, or install `MYjong-Setup-0.9.4.exe`. Photos, names, colors, high scores, and existing saved puzzles are preserved. New layouts apply to new puzzles.
