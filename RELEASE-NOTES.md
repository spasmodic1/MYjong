MYjong 0.9.8 adds an uninstall prompt to remove all MYjong data for the current Windows user. Choose Yes to permanently remove stored photo copies, saves, scores, settings and caches, No to keep them, or Cancel to stop. Updates preserve data. Original photos and externally saved backups are untouched.

MYjong 0.9.7 sets first-run defaults to Random layout, Relaxed difficulty, Photos & traditional tiles, Match the same person or pet, and Relaxed play. Appearance and audio defaults use Evening blue, porcelain Classic tiles, Comfortable text, names and blocked shading off, sounds on, music off, Garden walk/Moonlight tunes, and 45% volume. Race arrivals default to 5 seconds after the opening grace period; Memory reveals default to 4 seconds. The starter collection seeds photos without overriding these defaults.

MYjong 0.9.6 restores mixed incoming tiles without changing existing faces. Each drop matches an available face when possible; later drops supply missing partners. Race mode keeps counting down when no matches are open.

MYjong 0.9.5 repairs an unresponsive startup caused by a damaged packaged archive.

- Rebuilt the application from stable source files. Packaging now verifies every runtime file against its source before the build succeeds.
- Includes maximized launch and the welcome screen, custom menu colors and live tile previews, the Memory reveal timer, revised race drops and explicit full-board losses, and the red rabbit tile.
- Existing photos, names, settings, scores, and saved puzzles are preserved.

Install `MYjong-Setup-0.9.5.exe` to repair the affected 0.9.4 build.

MYjong 0.9.4 adds richer music, distinct layouts, and Memory mode.

- Six longer original arrangements layer piano-like and harp-like instruments, soft chords, bass, stereo room reflections and melodic variations. Menu and game tunes can be chosen separately and crossfade when menus open or close.
- Diamond now has pointed tips, Terrace has a stepped pyramid, and Butterfly has separated wings and a narrow body. Starting deals remain solvable at all difficulties.
- Memory mode starts with hidden faces. Clicking an available tile flips it over; choosing another hides the previous face. Matching pairs disappear. Flip animations respect reduced-motion settings.
- New puzzles receive a quick falling-tile deal animation. Reduced-motion users get an immediate board.

Use **Settings → Check for Updates**, or install `MYjong-Setup-0.9.4.exe`. Photos, names, colors, high scores, and existing saved puzzles are preserved. New layouts apply to new puzzles.
