# Garden visual refresh — 0.9.13

Created using the built-in image generation tool. The Spring scene was supplied only as a quality/style reference for the year-round garden. No personal photos were supplied. Final images were visually inspected in the application at desktop and narrow widths. Image conversion uses Sharp; interface layout and text are HTML/CSS.

Saved assets:

- `assets/branding/lakeside-garden.webp` — 1920 × 1080 default playing scene.
- `assets/branding/welcome-garden.webp` — 1920 × 1080 welcome scene.
- `assets/branding/icon-master-v2.png` — transparent icon master.
- `assets/branding/emblem-v2.webp` — interface emblem.
- `assets/icon.png` and `assets/icon.ico` — application and Windows icon exports; sizes 256, 128, 64, 48, 32, 16. Rebuild with `node tools/prepare-branding.cjs`.
